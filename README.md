# Site développeur Kevin Rosala

Projet Angular 22 avec deux pages : `/` (développeur, caméléon vert) et `/angelshield` (application, ange et bouclier cyan).

## Lancer le projet

Utilisez Node.js 22.22.3 ou plus récent dans la branche 22, ou Node.js 24.15.0 ou plus récent.

```sh
npm ci
npm start
```

Ouvrez http://localhost:4200.

## Construire

```sh
npm run build
```

Les fichiers statiques sont dans `dist`. Configurez votre hébergement pour servir `index.html` lorsqu’une route comme `/angelshield` est ouverte directement.

## Modifier

- Accueil : `src/home.component.html`
- Application : `src/angelshield.component.html`
- Routes : `src/main.ts`
- Thème et responsive : `src/styles.css`
- Visuels : `public/`
- Lien Google Play : `src/angelshield.component.ts`

Le ZIP contient les sources et les visuels, sans node_modules ni identifiants d’hébergement. Aucune collecte de données ni formulaire. La bannière est un visuel promotionnel fourni ; ce n’est pas une capture vérifiée de l’interface. Le site ne remplace pas la politique de confidentialité de l’application.
